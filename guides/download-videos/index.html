How to download web videos on Android with SnapSaver

Open a page, play its video, select a detected resource, and find your saved files. A practical guide to the SnapSaver Android browser.

Start with the Android app

SnapSaver combines a browser, media detection, a download manager, and a player. Install it from Google Play on Android 7.0 or later. This website explains the app; downloads run on your phone.

Save a video from a web page

  1. Open SnapSaver and enter the address of a page containing a video you are allowed to save. You can also copy a link or share it to SnapSaver from another app.
  2. Play the video. Many sites request the media only after playback starts, so wait for the player to load.
  3. Open the detected media list using the download control. Check the available items and choose the video you want. A page can contain previews, adverts, and more than one quality option.
  4. Start the download and check its progress in the download manager. Keep a working network connection and enough free storage.
  5. Open the completed item in the file manager to play it, rename it, or share it with another app.

MP4 files and M3U8 playlists work differently

An MP4 URL usually points to a media file. An M3U8 URL points to an HLS playlist that references smaller media segments. The playlist alone is not the entire video. Availability depends on the website, the playlist, and whether the referenced resources can still be accessed.

If the download does not appear

Refresh the page and start playback again. A visible player does not guarantee a downloadable resource: DRM, expired URLs, sign-in requirements, and unsupported players can prevent detection or downloading. See the detection and download troubleshooting guide for checks in order.

Finding the downloaded file

Check the app's completed downloads and file manager first. A file stored there may need to be shared or exported before it appears in another gallery or player. Do not delete app data as a troubleshooting step without preserving files you need.
